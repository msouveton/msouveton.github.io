This project forms part of my PhD research into the radiative characterisation of porous media. A ray tracing code using direct simulation Monte Carlo (DSMC) is available on my GitHub page. It is written entirely in Python and enables the calculation of directional transmittances and reflectances within a statistically homogeneous and isotropic fibrous medium.
